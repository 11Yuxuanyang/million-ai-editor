# 与君 AI｜老板内容记忆

## 目标

让企业老板看懂一个具体问题：内容团队真正缺的不是再多一个写手，而是一套能记住老板、调用老板既有判断的企业记忆。

## 观众

- 正在做老板 IP、企业账号或内容获客的经营者
- 已经雇了文案、剪辑，却仍被反复追问和解释拖住的老板

## 叙事

散落的信息 → 重复解释的成本 → 企业记忆收拢 → 老板只保留判断与确认 → 每次表达成为资产。

## 视觉母题

**企业记忆总线**：真实语音波形、项目文件、客户问题最初散落在人物周围；在中段被一条稳定的索引主线收拢；后半沿同一条主线被调用为观点、案例、素材、文案和剪辑。

## 视觉方向

- 工程档案感，而非科技广告或 PPT。
- 纸白 `#F3F0E8`、墨青 `#172A2F`、石墨灰 `#687276`；朱橙 `#E85A3A` 只用于唯一焦点。
- 人物始终是主角，证据和系统只解释他说的话。
- 真实材料优先：本期源视频、真实内容系统文档、真实 Pitch Deck 预览和真实项目文件名。

## 声音

- 口播为主，不铺喧宾夺主的音乐。
- 仅在前三秒镜头拉远和“老板本人”落点使用成熟来源的 whoosh / impact。
- 后文仅在真实界面确认或资料收拢时保留极轻微点击，不为每个动效配声。

## 交付顺序

1. 1920×1080 / 60fps 时间线与高质量 A-roll 中间件。
2. 1280×720 / 60fps 连续低清预览。
3. 用户确认后再渲染 1920×1080 / 60fps 正式母版。
