# Design Direction

## 构图主线

人物不退场。画面从“人物被资料包围”逐步变成“资料围绕人物有序工作”。

- **散落态**：资料各自有来源身份、方向和层级，位置错落但不压脸。
- **收拢态**：一条纵向索引脊柱成为画面稳定支点，材料向它汇聚。
- **调用态**：焦点沿索引移动，输出逐项落地为观点、案例、素材、文案、剪辑。
- **资产态**：已完成表达留在画面中，后来的表达叠加而不是覆盖。

## 字体层级

- 前三秒是编辑型大字，不使用正文字幕。
- 钩子只强调“老板本人”；“文案 / 剪辑”作为被排除项，尺寸小一档、低对比。
- 正文固定双语字幕：中文上方白色，英文下方亮橙色；系统字体、无描边、深色阴影。
- 关键词字可以跨前后景，但眼睛、嘴与关键动作不可被无意义遮挡。

## 动作语法

- 快入慢停，落地后保持，不往返弹跳。
- 摄像机推进或拉远必须与关键词、音效共同落点。
- 真实材料用轻 3D 透视和多层视差；不做等权截图墙。
- 转场优先使用物体边缘、索引线、文件翻页的匹配转场；不使用渐变光晕、粒子或无意义滤镜。

## 真实性

- 页面内容来自宇君 AI 现有内容系统与 Pitch Deck。
- 语音波形来自本期真实口播。
- 客户问题以匿名问题文本表达，不伪造客户身份与结果。
