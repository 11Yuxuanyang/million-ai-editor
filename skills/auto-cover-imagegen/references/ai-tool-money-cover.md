# AI Tool + Money Cover

Use this proven template for practical AI-tool tutorials where the viewer promise is: learn one named tool now and use it to produce a concrete business or income result.

Use an approved account cover as a style reference only when it exists in the current project or reference library. Never depend on a missing fixed path, and never copy old cover text into a new episode.

## Text Architecture

Use three levels only:

1. Urgency badge: `<YEAR> 必学`
2. Giant product/tool name: `<TOOL>`
3. Concrete outcome: `<RESULT> 必备`

Example:

```text
2026 必学
CODEX
赚 AI Money 必备
```

Do not copy the money promise when the episode is not about monetization. Preserve the three-level hierarchy but replace the result with the video's real payoff.

## Visual Formula

- One expressive presenter, framed large enough to recognize at thumbnail size.
- One dominant tool name; it must remain the largest text.
- One subordinate visual gag that turns the promise into an object, such as a terminal toolbox releasing coins.
- Cobalt blue field, vivid yellow tool name, clean white result line, black structure, and one small red urgency badge.
- Strong solid-color contrast and crisp editorial lighting; no generic AI gradient.
- Use the product name typographically when an authentic icon is unavailable. Never invent a fake logo.

## Composition

### 4:3

- Text occupies roughly the left 55-60%; presenter occupies the right 40-45%.
- Put the urgency badge above the tool name and the result directly below it.
- Keep the gag object in a lower corner, clearly secondary to the face and tool name.
- Preserve the presenter's eyes, mouth, and defining hand gesture.

### 3:4

- Generate separately; never crop the 4:3 cover.
- Stack urgency badge, tool name, and result in the upper half.
- Put the presenter in the lower half with the face still large.
- Move the gag object beside the torso or into a lower corner so it does not compete with the face.
- Keep mobile-safe margins around every word.

## Prompt Template

```text
Use case: ads-marketing
Asset type: Chinese short-video cover, <4:3 landscape | 3:4 vertical>, polished final image.
Input image: presenter identity and gesture reference. Preserve the recognizable face, hairstyle, age, skin texture, and expression.
Primary request: Generate a high-click cover for a practical <TOOL> tutorial with the concrete payoff <RESULT>.
Exact text to render, and no other text:
Badge: "<YEAR> 必学"
Main huge title: "<TOOL>"
Subtitle: "<RESULT> 必备"
Composition: <use the ratio-specific rules above>.
Visual gag: one concrete object that connects the tool to the result; keep it subordinate to the face and headline.
Style: premium Chinese short-video AI/business cover, bold systematic sans-serif type, very high thumbnail contrast, lively and slightly funny but not cheap, crisp editorial poster finish.
Color palette: cobalt blue, vivid yellow, clean white, black, and a small red accent; mostly solid colors.
Constraints: all text exact, front-facing, large, readable, and uncropped; preserve identity; no other words.
Avoid: distorted faces or hands, fake logos, pseudo-writing, excessive neon, muddy darkness, clutter, PPT/card layout, generic AI gradients.
```

## Reject When

- The tool name is smaller than the benefit line.
- The cover reads as a lecture slide instead of a thumbnail.
- The gag object becomes the main subject.
- The presenter is unrecognizable or the hand is malformed.
- The 3:4 version is merely a crop of 4:3.
- Any required word is wrong, blocked, or clipped.
