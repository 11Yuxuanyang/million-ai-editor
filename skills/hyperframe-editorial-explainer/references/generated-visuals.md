# Generated Visuals

生成画面用于解释不可拍摄的状态、建立隐喻、表现假设或补充情绪，不承担事实证明。

## 五阶段

1. **语义拆解**：列出角色、对象、关系、状态变化、动作顺序和必须真实的部分。
2. **资产生成**：独立生成需要单独运动的部件；精确文字、数字、箭头、图表留给代码。
3. **抠像与补全**：保留原色和 alpha；补全运动会露出的边缘、背面、手脚和连接。
4. **无重叠装配**：每个像素只属于一个活动组件；禁止低透明整图垫底造成重影。
5. **语义动画**：动作表达关系变化，而不是所有部件统一淡入/缩放。

## 视觉纪律

- 不默认加白色贴纸边、全局阴影、灰度/棕褐滤镜、纸张纹理、胶带、圆角卡或固定倾斜。
- CSS 负责装配，不偷偷重设计获批资产。
- 生成的页面、数据、新闻截图或人物行为必须明确是示意，不能混进证据链。
- 每个组件在亮/暗背景检查 alpha、绿边、断裂、重复和矩形裁切。

动态验收至少覆盖：入场前、各部件运动中、完整状态、信息交接、首个稳定可读状态和退场。
