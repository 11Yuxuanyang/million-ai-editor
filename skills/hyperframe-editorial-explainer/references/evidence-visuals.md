# Evidence Visuals

证据画面回答“观众为什么相信”。优先一手、可定位、可复查的真实来源。

## 选择

- 用官方网站、真实产品界面、原始论文/报告、仓库、原视频或当事方材料支撑具体主张。
- 记录来源 URL/路径、获取时间、许可/使用边界、与哪句文稿对应。
- 屏录先查询媒体卡的 reviewed event index，按 `in/out`、真实 UI 行为、OCR 和 claim class 定位；索引置信度不足或主张不匹配时才回看原视频并补充索引。
- 搜索结果页、二手转述和 AI 生成网页不能替代原始证据；找不到时降低表述强度或明确缺口。

## 呈现

- 先让观众看清“这是什么”，再通过框选、焦点、裁切、滚动或光标引到关键处。
- 页面上下文对可信度重要时保留整页结构；只需要一个对象时可局部裁切，但不能改变原意。
- 页面内精确文字保持真实，不用生成模型重写。引用很长时以画面定位加简短代码原生标签，不做整屏小字朗读。
- 多页快速证据需要共同构图锚点和可读停顿；浅景深聚焦场景读取 `focus-flash-cuts.md`。

每个证据镜头写入 source note、主张映射和动态验收帧。真实性、可读性和剪辑节奏必须同时通过。
