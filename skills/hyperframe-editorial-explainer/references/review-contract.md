# 解释画面自检

本文件是旧项目的兼容入口，不是独立门禁。新任务只在连续预览中做以下快速自检，结论直接回填本期分镜。

## 分镜自检

- 每个 beat 的画面动作能否解释对应 meaning，而非仅制造变化？
- 证据、生成、推断和装饰是否被明确区分？
- 关键文字、数字、人物和来源在动态画面中是否可读？
- 声音、动作和语义重音是否对齐？

## 动态验收

为高风险镜头捕获首帧、动作前、中、后和稳定可读状态；复杂循环还要检查接缝。人物看口型和遮挡，网页看上下文与焦点，生成资产看 alpha/部件，数据看尺度和标签，转场看共享动机。

## 新手法沉淀

新手法只有在真实单期动态预览中有效、被成片保留并具备可复现参数时，才进入 technique library：

1. 先写 `candidate` 卡；
2. 记录意图、前提、禁用条件、参数、实现与预览证据；
3. 不因“做出来了”就升级为 approved；
4. 实现或使用边界改变后，在下一次连续预览中重新判断。

全片完成后可由一个未参与制作的 Agent 快速查看分镜、时间线和连续预览是否一致；不再生成独立审核链或逐层报告。
