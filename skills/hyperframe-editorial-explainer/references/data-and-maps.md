# Data And Maps

只有关系比单句更难理解时才使用图表、流程图或地图。先写清问题，再选视觉编码。

## 选择

- 时间变化用折线/面积；离散比较用条形；组成只在类别少且差异清楚时用堆叠或饼。
- 流程用节点与有方向的边；因果链需区分事实、推断和假设。
- 地理位置影响含义时才用地图；否则用排序、分组或距离关系更直接。
- 抽象等高线用 `d3-contour` 从确定性标量场生成；真实地理等高线用 MapLibre + 真实 DEM/矢量数据。不要手画波浪冒充地形，也不要把抽象纹理称为真实地图。
- 一个数字若足以表达，不画仪表盘。

## 事实门

- 记录实际数据源、统计口径、时间窗口、单位、分母和主要排除项。
- 不补齐不存在的数据，不把估算画成实测，不用视觉尺度夸大差异。
- 标签、数字、坐标和关系线代码原生；地图底图和行政边界注明来源与时点。

## 动作

动画按阅读顺序揭示比较或因果，不让所有元素同时飞入。镜头结束前保留稳定全貌，让观众完成理解。跨人物或真实事件时，同时读 `people-treatment.md` 或 `evidence-visuals.md`。
