# Focus Flash Cuts

用于多个真实网页/文章/仓库/产品页以同一中心锚点快速切换，并通过浅景深把注意力压到页面内真实词句。它是一种可复用手法，不是隔离上下文的子 Agent。

## 适用门

仅在以下条件同时成立时使用：

- 多个真实整页本身构成证据链；
- 观众需要感到“同一问题在多处反复出现”；
- 页面上下文必须可辨，焦点词又需瞬时突出；
- 快切比逐页讲解更符合当前节奏。

单页证明、普通截图轮播、开场标题或生成页面不使用本手法。需要人物、数据或生成解释时可同时跨读对应视角。

## 前置资产

1. 为每个页面保存真实来源、许可、全页截图、目标原文和 OCR 数据。
2. 使用 `scripts/preflight_focus_assets.py` 检查截图身份、尺寸、OCR 命中和目标边界。
3. 使用 `scripts/derive_focus_layouts.py` 从 OCR box 计算共同锚点、缩放和页面位置；不要手猜 CSS 偏移。
4. 以 `assets/focus-layout-spec.template.json` 建立布局数据，以 `assets/focus-depth-rig.css` 作为纯景深装配起点。
5. 切换音效必须是有许可、语义正确的短促机械/相机/纸张 cue，并保存来源。

## 画面语法

- 首帧先让至少一个页面身份可识别；焦点词保持真实页面字体和位置。
- 每页全尺寸铺底：远场模糊层保持页面上下文，清晰层用同一几何裁剪显露目标区域。
- 焦点中心尽量稳定，页面在其下切换；不同词长通过计算后的 scale/position 对齐。
- 每次切换包含短促入射、极短清晰停顿和干净离开。节奏可加速，但不能快到 OCR 词不可读。
- 不在页面上重新打一个更漂亮的假标题，不以统一卡片皮肤覆盖真实证据。

## 验收

逐页检查：来源正确、目标原文准确、整页无拉伸、焦点裁剪与模糊底层像素对齐、非目标区无双影。密集采样每次切换前/中/后，确认无空帧、跳位、接缝和音效错拍。

通过动态预览与独立审核后，才把此手法的实际参数和预览路径写入 technique card 的证据；当前卡保持 `candidate`，不能因存在脚本就视为 approved。
