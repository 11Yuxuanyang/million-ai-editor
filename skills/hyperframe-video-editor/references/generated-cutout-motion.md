# Generated Cutout Motion

当一段口播需要 VOX 式人物比喻、拆件动画或生成物件时读取。生成图是素材，不是成镜：

`语义设计 → ImageGen 拆件 → 抠图/补全 → 组件化 → setup/action/result → 连续预览`

## 先决定动作

- 写清这拍解释什么，以及观众最终看见的因果关系。
- 真实证据负责证明；生成画面只解释、比喻、情绪或结构示意，不能冒充真实事件。
- 先列出会独立运动的组件：人物、物体、输入、连接、结果、前景和必要阴影。精确文字、数字、箭头和关系线留给代码。
- 每句重新设计人物、道具、动作和场景；不要把上一期的一张生图、姿势或蓝色风格换字复用。

## ImageGen 输出

- 一次生成一个明确视觉工作，主体完整、四周留有运动余量、无伪文字、无多余人物。
- 需要独立运动的姿势、手、灯泡、硬币、设备或结果分别生成；背景使用可去除的纯色或独立背景层。
- 抠图后检查 RGBA、透明边缘、发丝、眼镜、手指和所有运动会露出的区域；缺失部分先补全再进动画。
- 不默认白描边、全局阴影、贴纸倾角、纸张纹理、灰度、固定蓝色或肉粉色。材质和配色由本期画面决定。

## 授权人物

只有用户已授权的常驻人物可走真人生成路径：

- 在本期记录身份参考与同意范围；锁定脸型、眼镜、发型、肤色和服装。
- 每个语义姿势独立生成并相互校对，人物必须可辨认，手部和肢体完整。
- 大头比例来自生成结果，不靠统一 CSS 描边。两个人的大头分成独立 alpha，错拍进入并反相轻摆。
- “思考 → 灵感 → 灯泡”至少拆成思考人物、顿悟人物、灯泡三个组件，动作顺序就是含义。
- 生成形象只作为示意表演，不能声称人物真实做过该动作。

## 组件与动画

- 独立运动的部分使用独立 alpha；相邻遮罩不能重复占用同一像素，也不要在拆件后保留一层半透明整图垫底。
- 在 HyperFrames 主时间线调用 `motion.generated.cutout-sequence.v1` 的实现，或按本期动作改造。
- 至少出现可辨认的 setup、action 和 result：例如资料进入机器、机器处理、结果落位；人物思考、同伴顿悟、灯泡亮起。
- 快速进入，给结果可读停留，再干净交回人物或真实证据。不要让所有组件做同一种淡入、弹跳或旋转。
- CSS 只负责排布和运动，不重画已经确认的生成资产。

## 连续预览检查

观看进入、动作峰值、结果停留和退出：

- 不得有脏边、矩形裁口、缺手缺物、断裂连接、重复人物、重影或双阴影。
- 不得出现身份漂移、眼镜或发型变化、额外人物、异常手部、头身接缝。
- 不得把实拍误变黑白，也不得把生成文字当作事实正文。
- 如果整段只是“一张图淡入或缩放”，它仍是静态插图，不算 VOX 动画。

连续低清成片按主剪辑 Skill 统一观看和一次快速审核，不为生成拆件另设审核链。
