# 稳定制作参数

数值和开关只读项目 `config/editorial-defaults.json`；本文件说明执行方法，不复制第二套参数。

## 素材准备与粗剪

1. 用 `ffprobe` 建立源文件清单，保留用户上传顺序。
2. 配置启用逐素材并行时，每个源文件独立检查首尾；机器资源不足则分批并行，不改变逻辑顺序。
3. 只剪配置允许的首尾停顿、开拍低头和结束静默。中间口播默认完整保留；有意设计的末尾动作不得因静音自动删除。
4. 记录每段保留区间，并以这些区间拼接 A-roll。不要通过静音阈值重写用户已经完成的中段粗剪。

## 中文转录与双语字幕

1. 没有可靠转录时先从保留音频提取单声道 ASR 文件，再调用配置中的 `preferredEngine`；中文默认使用豆包中文 ASR。
2. 凭据只从获准的环境变量或本机密钥源读取，不写入 Skill、项目文件、日志或成片。
3. 原文用于理解、专名和错字校正。音频与原文冲突时以真实口播为准；口误按用户要求标注，不偷偷改写录音内容。
4. 中文校对完成后按同一字幕段生成英文译文，不让中英文使用两套时间轴。
5. 字幕样式、上下顺序、字体、位置和阴影读取配置；开头字幕范围再读取审美偏好和单期指令。

## `1.1×` 与统一时钟

- 配置要求变速时，对实拍时基素材和同步录音只应用一次；静态图、字幕、动画、音乐和转场不单独变速。
- 视频使用 `setpts=PTS/rate`，音频使用对应 `atempo` 并保持音高。
- 字幕、镜头、动画和声音落点全部使用变速后的统一时钟。
- 已有可靠变速母素材时直接复用，不再次加速。

可按需执行：

```bash
python3 scripts/retime_media_1_1x.py --output-dir <episode>/retimed <source...>
python3 scripts/retime_timing_1_1x.py <transcript.srt> --output <episode>/retimed.srt
```

## 对白声音

- 先测量，再用 clip gain、轻压缩、自动化、降噪或限制器达到配置目标；不要盲加固定增益。
- 对最终编码文件重新测量 integrated loudness 和 true peak，AAC 编码后仍须满足上限。
- 处理不得改变音频起点、口型同步或字幕时钟。

## 预览与母版

- 预览媒体可以使用配置中的代理规格，HyperFrames 画布保持正式比例。
- 用户批准连续预览后才把代理替换为高质量源素材并输出正式母版。
