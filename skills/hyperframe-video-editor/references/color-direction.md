# 配色设计

把配色当作导演工作，不当作禁用颜色清单。

## 时机

先看完文稿、人物和真实素材，再立即完成配色设计，然后才写完整分镜。不要先做镜头、后补颜色。

## 先决定四个角色

在 `MOTION-STORYBOARD.md` 里直接写：

| 角色 | 它负责什么 |
| --- | --- |
| `地色` | 决定画面的空气、时间和情绪。可以是背景，也可以来自实拍环境。 |
| `内容色` | 保证人物、正文、证据和主要物体清楚可信。 |
| `结构色` | 连接章节、路径、卡片、线条或同一视觉系统。 |
| `语义强调色` | 只在真正需要观众立刻看到的词、数字、风险或结果上出现。 |

为每个角色给出实际色值或素材取色，并写一句用途。角色可以共用颜色，也可以在章节中有控制地变化。

## 怎么选

1. 先看人物肤色、服装、场景、真实素材和品牌色。
2. 再判断本期情绪：冷静、压力、希望、危险、温暖、讽刺或其他。
3. 用明度、冷暖、饱和度和面积关系建立主次，不靠效果堆出“高级感”。
4. 让强调色跟着叙事移动；它出现在哪里，观众就应该看哪里。
5. 让开头、正文、证据、解释动画和片尾属于同一色彩世界，但允许章节有变化。

## 不可改写的颜色

保持人物肤色自然。保持品牌、产品界面、图表含义和真实证据的识别色准确。需要改变它们时，必须有明确的叙事理由，不能只是为了统一画风。

## 进入分镜前确认

在写镜头前确认三件事：

- 第一眼是否知道看哪里？
- 人物和证据是否仍然可信？
- 全片是否像同一个色彩导演完成？

答案不清楚时先把颜色角色、光影方向和面积关系定清楚，不带着未完成的配色进入实现。制作阶段只检查执行是否偏离，不逐镜重新设计配色。
