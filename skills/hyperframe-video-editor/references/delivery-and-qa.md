# 连续预览、审核与交付

## 连续预览

先生成一条从头到尾可正常播放的低清版本。主剪辑 Agent 必须完整观看，直接检查理解、人物表演、真实证据、节奏、遮挡、字幕和声音；发现问题就回到时间线修改。

不要建立抽帧验收、接触表、逐镜打勾或逐帧报告。连续播放和用户观看才是视觉判断依据。

## 一次轻量审核

低清版本稳定后，spawn 一个未参与制作的 Sol，给它：

- 完整 `MOTION-STORYBOARD.md`
- 实际成片代码和关键素材引用
- 一条可连续播放的低清预览或预览地址

它只检查两类问题：

1. 分镜、时间线和代码是否一致，是否存在错误路径、状态残留、重复效果、错位或不同步。
2. 连续观看时是否存在明显的叙事断裂、构图冲突、配色跳脱或效果破坏人物表演。

只返回阻塞问题和最短修改建议。它是代码与连续性复核，不代替主 Agent 和用户的真实观看，也不扩展成多层审核。

## 用户批准后

用户批准连续低清预览后才输出正式母版。最终只确认：

- 代理已替换为正确的高质量源素材。
- 全片可解码，没有黑帧、破图、缺声或意外停顿。
- 音画同步，字幕与对白一致，人物和重要信息无遮挡。
- 分辨率、帧率、编码、时长和声音符合 `config/editorial-defaults.json`。

用 `ffprobe`、响度测量和完整播放确认，不再新增审核文件或门禁。
