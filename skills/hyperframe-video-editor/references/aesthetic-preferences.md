# 用户审美偏好

这里只记录用户明确表达或在成片中反复认可的审美。它是创作先验，不是镜头配额。

| 分类 | 偏好 | 使用判断 |
| --- | --- | --- |
| 人物小窗 | 全屏真实素材仍需要保留说话人时，可用圆形或圆角小窗承载人物。 | 小窗服务人物连续性，不把文字标签机械地做成一圈圆点或卡片。 |
| 配色偏好 | 文字强调默认避开绿色。 | 避免大面积肉粉、灰粉、裸粉和低饱和珊瑚色；只有品牌色、证据识别色或明确语义需要时才使用绿色。 |
| 抽象动效 | 点线场和等高线必须真的持续运动。 | 可在纯黑章节转场使用；不用随机曲线、静态点网或截断线条冒充动效。 |
| 点阵 | 波点、点阵和点线场主要承担换章。 | 转场结束即退出，不长期压在正文人物上。 |
| Vox | 具象比喻可以使用 ImageGen 生成独立 Vox 风格素材。 | 每个场景生成与台词对应的新画面；涉及两位创作者时使用真实形象参考，只作解释，不作事实证据。 |
| 滤镜 | 不给人物和真实素材随意套统一滤镜。 | 只有叙事、时空或素材统一确有需要时局部处理。 |
| 开头选择性虚焦大字 | Source Han Sans SC Heavy 或同等级系统重黑体，主体实心、字形稳，允许用斜体强调少数关键词。 | 适合短促口播冷开场：人物与真实素材先建立关系，普通词直接清晰，最多一至两个语义锚点在最终位置稳定虚焦后用单条连续长尾曲线聚焦。强调色默认避开绿色，品牌、证据识别或明确语义需要时例外。不要方向模糊、晃动、回弹、过程推近、横竖装饰线或字幕容器。参数基准见 `../assets/opening-display-type/approved-selective-defocus-v2.json`。 |
| 聚焦快切 | 只有用户明确点名时使用。 | 普通“重点”不能自动推断成 Focus Flash Cuts。 |
| 推拉聚焦音效 | 快速推近、拉远或由虚到实，优先短促的反向吸入式 whoosh；声音与镜头同起，能量峰对齐主要位移与聚焦落稳处。 | 用户确认的 02 是声学参考，不是已授权商业母带。避免用起点重、低频“咚”为主体的普通 whoosh 代替；具体身份、候选和授权见 `sound-direction.md`。 |

## 写入

用户明确表达时立即更新；相同选择在多个获批成片中反复出现时可标为常用。单期颜色、坐标和参数不进入这里。
