# 统一强制项

这里仅放必须统一执行的规则。稳定数值以仓库 `config/editorial-defaults.json` 为机器事实源，不从聊天或旧视频反推。

| 统一项 | 必须怎样做 | 事实源 |
| --- | --- | --- |
| 实拍素材速度 | 所有实拍时基素材和同步录音按配置统一 `1.1×`，只应用一次并保持音高。 | `sourceRetime` |
| 时间轴 | 字幕、镜头、动效和声音落点全部使用变速后的统一时钟。 | `sourceRetime` |
| 画布与交付 | 分辨率、帧率、编码和画布方向读取当前配置。 | `delivery`、`master` |
| 对白响度 | 预览和母版都达到配置中的统一较响目标，并遵守 true peak 上限。 | `preview`、`master` |
| 素材首尾 | 只清理低头开场、开口前停顿和说完后的无意义停顿；保留中段完整表达、玩笑与有意义的尾部动作。 | `roughCut` |
| 前五秒 | 前三秒作为最高注意力区，前五秒完成钩子；不叠正文双语字幕，只使用本期设计的精简展示字。 | `rhythm`、`captions.scope` |
| 正文字幕 | 开头钩子后统一使用配置中的系统字体双语字幕；中文在上、英文在下，无描边、无黑框。 | `captions` |
| 画面节奏 | 不允许达到十秒仍无有意义变化；变化必须服务理解、证据、情绪或节奏。 | `rhythm` |
| 装饰竖线 | 任何画面都不使用卡片或标题左、右侧的装饰性竖向强调线；用层级、留白、色块或构图建立强调。 | 用户全局审美要求 |
| 正式母版 | 用户批准连续低清预览后才输出正式母版。 | 项目工作规则 |
| 事实与证据 | 不虚构事实、来源、许可、人物行为、数据或产品能力；生成画面不冒充真实证据。 | 项目安全规则 |
| 发布与删除 | 未经用户明确授权，不发布、不永久删除。 | 项目安全规则 |

## 改变

用户明确要求全局统一，或同一判断在多个获批成片中反复成立时，才能提炼到这里。涉及机器参数时，同一次修改必须更新 `editorial-defaults.json`；单期例外只写在本期目录。失效、重复或妨碍判断的规则直接合并或删除。
