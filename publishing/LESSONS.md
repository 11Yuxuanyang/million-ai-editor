# Editing And Publishing Lessons

## Editing

- Use audio transcription as the primary understanding source. Frame sampling is only for visual QA.
- A-roll cannot sit unchanged for 10 seconds or more. Add a scale change, B-roll, PIP, cutaway, or typography beat before the viewer feels the hold.
- B-roll should add concrete evidence, not decorate. Prefer real product icons, product screenshots, video stills, and public commercial-safe footage.
- Do not overfill the canvas. Some moments should stay clean, especially when the spoken point is already dense.
- When using behind-person typography, vary depth and placement: some text behind the cutout, some in front, one or two full-body banner words when needed.
- Avoid cheap effects: no shake-for-shake, no mismatched shadows, no unreadable small type, no diagrams without rendered visual inspection.

## Covers

- Default future cover spec: 4:3 first, then vertical if the platform needs it.
- Cover must be readable at phone thumbnail size. High contrast beats tasteful but low-energy color.
- Tags: at most 5.

## Uploading

- Use the user's real Google Chrome session for Douyin. Standalone Playwright usually loses login state.
- Use queue metadata exactly. Do not improvise title or tags during upload.
- Stop before final publish unless the user explicitly confirms that the prepared page is correct.
- If Douyin warns that a cover is bad, report it and leave the page open instead of redesigning during upload.
