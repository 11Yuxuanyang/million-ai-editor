# HyperFrame 素材库

这里保存可运行的镜头、布局、转场、声音与许可素材。语义判断在 `library/techniques/registry.json`，实现路径在 `registry.json`，获批画面在 `library/references/`。

## 使用顺序

1. 从画面能力索引选择语义任务和 `technique ID`。
2. 沿条目的 `assetRefs` 找到本表中的可运行实现；有 `reference` 或 `preview` 时只看相关获批画面。
3. 按新素材重新设计构图、几何和时间点；不要整幕复制旧视频。
4. Lottie、音效和外部素材必须保留来源、许可证与本地文件。
5. 当前实体、品牌图标和新闻素材仍需实时检索，不能用旧库代替事实核验。

资产名统一采用专业英文术语；`aliases` 仅保存旧称或中文检索词。首次沟通可写“术语 + 短中文释义”，后续只使用 `professionalTerm` 或 `SL-ID`。

## 状态

- `approved`：已在连续预览或正式成片中被保留，可在符合条件时复用。
- `approved-conditional`：技术上通过，但必须满足条目中的明确前提。
- `reference-only`：只用于构图或镜头理解，不能直接作为成片素材。
- `rejected`：不进入正式注册表；原因保留在原项目的素材说明中。

## 入库门槛

- 已在连续预览或正式成片中真实使用并被保留；最后一次快速审核或用户确认都可作为依据。
- 有明确语义工作，不是纯装饰。
- 能说明何时使用、何时不能使用。
- 路径、来源、许可证和技术规格完整。
- 不包含用户 A-roll、一次性 B-roll、字幕成片片段、草稿或已否决方案。

## 目录

- `previews/`：审核通过的镜头参考帧。
- `motion-recipes/`：可复用的 GSAP/CSS 镜头骨架。
- `overlays/`：已记录来源、许可、合成方式与技术规格的可复用叠加素材。
- `lottie/`：本地化并记录许可的动效素材。
- `sfx/`：可追溯或本地合成的独立短音效。
- `reviews/`：已有许可、透明合成或高风险资产的简短核验记录；不是每次复用的额外门禁。

路径必须相对仓库、可被 Git 交接，不能把 `videos/` 下的单机项目当作唯一实现。
