# 百万剪辑 OS 开源发布文稿

我俩要做一个违反祖宗的决定：

**给我开源！**

一个多月的时间，细致拆解 20 多位创作者的剪辑手法，加上我俩对爆款短视频的理解，再经过 10 多条真实视频的测试。

今天，百万剪辑 OS 正式开源。

给我进入全民创作时代！

我们希望所有人都能享受到创作的快乐，把注意力放在创造上。

这套剪辑系统部署完成后，你只需要上传拍摄素材。AI 会分析素材、理解内容、设计分镜、配字幕、做动画，再交给你审片和确认。

百万剪辑 OS 不只想帮助不会剪辑的朋友迅速拥有一套顶级剪辑师的工作方法，也希望它成为大家真正能使用、能赚钱的工具。

我们率先拿自己 2022 年开的自习室和朋友的自习室开刀。

接下来就看看，我们研发的 AI 剪辑师到底有没有水平：能不能支撑我们暴力剪辑，也能配合流量打法，真正为本地商家获客。

虽然 FDE 工程师肯定不等于 AI 剪辑师，但我俩目前只有先活下去，才有希望。

没错，我们的进程非常缓慢。

所有的困难、愁苦，以及那些找不到原因的日子，大家都看不到。太多人只想要粗暴的结论和结果。

但是，在没有正反馈的日子里，我们一直在学习。

真正的大菜还在开发。

稍安勿躁。

我们保证，账号永远不会停更。
